# SafeRecovery Demo

A modern financial recovery and debt collection platform demonstration.

## Project info

This project is a demonstration of a financial recovery solution, built with modern web technologies.

## Getting Started

To get started with the project, follow these steps:

### Prerequisites

- Node.js (v18 or later recommended)
- npm

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/anupam1005/cosmos-login-site.git
   ```

2. Navigate to the project directory:
   ```sh
   cd cosmos-login-site
   ```

3. Install the necessary dependencies:
   ```sh
   npm install
   ```

### Development

Start the development server with auto-reloading:
```sh
npm run dev
```

### Building for Production

To create a production build:
```sh
npm run build
```

The output will be in the `dist` directory.

## Technologies Used

- **Framework**: Vite
- **Language**: TypeScript
- **Library**: React
- **UI Components**: shadcn-ui
- **Styling**: Tailwind CSS
