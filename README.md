# SafeRecovery | Financial Recovery Solutions

![SafeRecovery Logo](public/logo.svg)

SafeRecovery is a premium, secure, and ethical platform designed to streamline financial recovery and debt collection operations. This repository serves as a complete demonstration of the platform's capabilities, from automated outreach to advanced case management.

## 🌟 Key Features

- **Omnichannel Recovery**: Integrated SMS, Email, and Voice outreach.
- **Skip Tracing**: Advanced search capabilities to locate and engage unreachable debtors.
- **Legal Workflow**: End-to-end management of legal proceedings and court documentation.
- **Real-time MIS**: Granular reporting and performance analytics for recovery managers.
- **Compliance First**: Built-in adherence to FDCPA, TCPA, and other regulatory guidelines.
- **Bank-Grade Security**: SOC2 Type II certified infrastructure and AES-256 encryption.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: Version 18.0 or higher.
- **npm**: Version 9.0 or higher.

### Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/anupam1005/cosmos-login-site.git
   cd cosmos-login-site
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Access the platform**:
   Open `http://localhost:8080` in your browser.

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Vite
- **UI Framework**: Tailwind CSS, shadcn/ui
- **Animations**: Framer Motion
- **State Management**: React Query (TanStack)
- **Database/Auth**: Supabase (Demo uses a mock client for easy exploration)
- **Deployment**: Optimized for Vercel

## 📁 Project Structure

- `/src/components`: Reusable UI components and layout blocks.
- `/src/pages`: Main application screens (Landing, Dashboard, Admin, etc.).
- `/src/integrations`: API clients and third-party integrations (Supabase).
- `/src/hooks`: Custom React hooks for data fetching and UI logic.
- `/public`: Static assets, logos, and favicons.

## 🔒 Security & Compliance

SafeRecovery is designed with a "Security-First" approach:
- **Data Encryption**: All data is encrypted at rest and in transit.
- **Audit Logs**: Every action in the system is logged for compliance audits.
- **Role-Based Access**: Granular permissions for agents, managers, and admins.
